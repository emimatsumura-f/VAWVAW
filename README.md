# VAWVAW

パソコンのデスクトップに住む、オレンジのもふもふペットです。
画面のすみで呼吸したり、歌ったり、走り回ったりします。ほかのウィンドウより手前に表示され続けます。

## 動作環境

- Windows 10 / Windows 11
- 追加のインストールは不要です（Windowsに最初から入っている PowerShell で動きます）
- Mac では動きません

## はじめかた

1. `VAWVAW` フォルダを好きな場所に置きます
2. フォルダの中の **`start_VAWVAW.vbs`** をダブルクリックします
3. 画面の右下に VAWVAW が現れ、「**あげぽよー!!**」と言えば起動成功です

すでに VAWVAW が出ているときに `start_VAWVAW.vbs` をもう一度ダブルクリックすると、新しく起動し直します。

## さわり方

| 操作 | どうなる |
| --- | --- |
| クリック | 跳ねて喜び、「行くぜぇ‼」「ねぇもっと!」「もっと踊れ」「そんなもんかい」のどれかを言います |
| ダブルクリック | 再起動します（「あげぽよー!!」と表示され、下の30分・50分・60分の時間も0分に戻ります） |
| ドラッグ | 好きな場所に移動できます（場所は次回も覚えています） |
| 右クリック | メニューを開きます |

### 右クリックメニュー

- **なでる**：クリックしたときと同じです
- **ごはん**：クッキーを食べて、おなかが増えます
- **あそぶ**：ぴょんぴょん跳ねます（なつき度が上がり、おなかが少し減ります）
- **いっしょに作業する（25分）**：25分間となりで応援します。終わると喜びます。もう一度選ぶと途中でやめられます
- **大きさ**：大・中・小 から選べます
- **パソコン起動時に表示する**：選ぶと、次からパソコンをつけたときに自動で出てきます。もう一度選ぶと解除します
- **VAWVAWをしまう（終了）**：VAWVAW を終了します

## さわらずに置いておくと

| 経過時間 | 動き |
| --- | --- |
| 30分 | 「**Good!**」と言って、マイクを持って歌います（3分間） |
| 50分 | 「**Last!!!**」と言って、画面の下をゆっくり走り回ります（60分まで） |
| 60分 | 仰向けに寝転がって、Zzz と眠ります |

クリック・ドラッグ・メニュー操作をすると、時間は0分に戻ります。

そのほか、ときどき独り言を言います。

- まだまだだな / 騒げー!! / 馬刺したべた / 声だせー!! / そでれ帰れんのか？ / 俺が来た!!

## なつき度とおなか

- **なつき度**（最大10）：クリック、あそぶ、作業の完了で上がります
- **おなか**（最大10）：ごはんで3増え、あそぶと1減ります。何もしなくても2時間ごとに1ずつ減ります
- おなかが2以下になると、ときどき「おなかすいた…」と言います

記録はパソコンごとに保存されるので、フォルダを人に渡しても、相手の VAWVAW は最初から始まります。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `start_VAWVAW.vbs` | 起動用ファイル（これをダブルクリック） |
| `Bau.ps1` | VAWVAW 本体のプログラム |
| `bau.png` | キャラクターの画像 |
| `README.md` | この説明書 |

なつき度・おなか・表示位置の記録は `%APPDATA%\Bau\state.json`、動作の記録は `%APPDATA%\Bau\vawvaw.log` に保存されます。

## 困ったとき

- **ダブルクリックしても起動しない**：`start_VAWVAW.vbs` を右クリック →「プロパティ」→ 下のほうの「許可する」にチェック →「OK」を押してから、もう一度ダブルクリックしてください（インターネットやメールから受け取ったファイルでよく起きます）
- **会社のパソコンで起動しない**：セキュリティ設定で、この種類のファイルの実行が禁止されている場合があります
- **アンインストールしたい**：右クリックメニューで「パソコン起動時に表示する」を解除し、「VAWVAWをしまう（終了）」を選んでから、`VAWVAW` フォルダを削除してください。記録も消したい場合は `%APPDATA%\Bau` フォルダも削除します
